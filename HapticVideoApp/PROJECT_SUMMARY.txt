🚀 SETUP STEPS (2 MINUTES!)
════════════════════════════════════════════════════════════════

STEP 1: Create Xcode Project (1 min)
  1. Extract HapticVideoApp folder
  2. Open Xcode
  3. File → New → Project → iOS App
  4. Name: HapticVideoApp
  5. Interface: SwiftUI, Language: Swift
  6. Save IN the extracted HapticVideoApp folder

STEP 2: Add Files (30 sec)
  1. Delete auto-generated ContentView & App files
  2. Drag all folders into Xcode: Models, ViewModels, Views, Services
  3. Drag root files: HapticVideoAppApp.swift, ContentView.swift
  4. Check "Copy items if needed"

STEP 3: Add Info.plist Permissions (30 sec)
  Open Info.plist, add 3 keys:
  • Privacy - Camera Usage Description
  • Privacy - Photo Library Usage Description  
  • Privacy - Microphone Usage Description

STEP 4: Run! (10 sec)
  Press ⌘ + R

DONE! App launches immediately! 🎉

🤖 AI HAPTIC GENERATION
════════════════════════════════════════════════════════════════

Current Implementation:
• Generates sample haptic events every 2 seconds
• Randomized intensity (0.5-1.0) and sharpness (0.3-0.8)
• Alternates between: Transient, Impact, Continuous
• Saves as JSON file locally

Replace With Your ML Model:
1. Open: ViewModels/UploadViewModel.swift
2. Find: generateHapticsWithAI(for videoURL: URL)
3. Add your logic:
   - Extract video frames (Vision)
   - Analyze audio (AVFoundation)
   - Run ML inference (Core ML / API)
   - Convert to HapticEvent array

Output Format:
```swift
HapticEvent(
    time: 3.5,           // seconds into video
    intensity: 0.8,      // 0.0-1.0
    sharpness: 0.6,      // 0.0-1.0
    duration: 0.2,       // seconds
    type: .impact        // or .transient, .continuous
)
```

🐛 COMMON ISSUES
════════════════════════════════════════════════════════════════

"Cannot find LocalDataStore"
→ Ensure all files added to target
→ Check Target Membership in File Inspector

Build errors
→ Clean build folder (⌘ + Shift + K)
→ Rebuild (⌘ + B)

Haptics don't work
→ Must use REAL iPhone, not simulator!
→ Check: iPhone 8 or later
→ Check: System Haptics enabled in Settings

Videos don't save
→ Check console for errors
→ Try shorter video (under 1 min)
