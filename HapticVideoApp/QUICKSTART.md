# QUICK START - 2 Minutes to Running!

## Prerequisites
- Mac with Xcode 15+
- That's it!

## Steps

### 1. Create Xcode Project (1 min)
```
1. Extract HapticVideoApp folder
2. Open Xcode
3. File → New → Project
4. iOS → App
5. Name: HapticVideoApp
6. Interface: SwiftUI
7. Save IN the extracted folder
```

### 2. Add Files (30 sec)
```
1. Delete default ContentView.swift and HapticVideoAppApp.swift
2. Drag all folders from Finder into Xcode:
   - Models/
   - ViewModels/
   - Views/
   - Services/
3. Drag root files:
   - HapticVideoAppApp.swift
   - ContentView.swift
```

### 3. Add Permissions (30 sec)
```
Open Info.plist, add:
- Privacy - Camera Usage Description: "For recording videos"
- Privacy - Photo Library Usage Description: "For selecting videos"
- Privacy - Microphone Usage Description: "For audio"
```

### 4. Run! (10 sec)
```
Press ⌘ + R
Done! 🎉
```

```

```
